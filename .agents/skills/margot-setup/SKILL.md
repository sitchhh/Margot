offline file preparation from actual account authentication and live verification.

handoff questions with Maggie as setup progresses. Carry confirmed facts forward
without re-asking; never turn the provisional funding estimate into approved copy.
Use Maggie's selected accounts; never reuse the developer's connections by default.
Complete all independent local steps while a connection is unavailable. Help Maggie
through the plugin sign-in UI, but don't ask for credentials in chat.

Assume no Supabase account exists on first use. Walk Maggie through creating her
account, organization, and dedicated Margot project; then connect the Supabase
plugin, followed by Gmail. If she already has an account or project, verify her
selection and skip completed steps. Use “plugin” in user-facing instructions and
explain MCP only when needed. Maggie completes sign-up and permission screens
herself. After installation, start a fresh project chat to load the tools and
resume from the saved local profile and connection checks.

Report local readiness and each live capability separately. A saved project ref,
installed plugin, successful doctor, or generated migration is not proof of a
working connection. Preserve observed results in ignored `.local/connection-check.md`.
Do not require self-test email sending unless Maggie requests it; label it unverified.
